# Datasets

The archive intentionally does not bundle the large input graph files. Each case study includes a download script for the datasets it uses; inspect that script and the corresponding dataset source before running it.

For a reproducible submission, record for each downloaded graph:
- original source URL and dataset/version;
- retrieval date;
- license or redistribution terms;
- checksum (for example, `sha256sum filename`);
- preprocessing used by the experiment (directed versus symmetrised, duplicate/self-loop handling, and vertex-ID mapping).

The recorded CSVs and graph-statistics files describe the workloads used for the archived results, but do not replace the original dataset files or their licensing terms. Do not redistribute data unless its terms permit it.
